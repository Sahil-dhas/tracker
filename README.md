# Habit Matrix 2026 – Android APK

1. Create a new GitHub repository and upload everything in this folder
   (including the hidden .github folder), or run:
   git init && git add . && git commit -m "init" && git branch -M main
   git remote add origin <your-repo-url> && git push -u origin main
2. Open the repo's Actions tab. The "Build APK" workflow runs on push
   (or click "Run workflow"). It takes about 3-5 minutes.
3. Open the finished run, download the "habit-matrix-apk" artifact, unzip it.
4. Copy app-debug.apk to your phone and open it. Allow "Install unknown apps"
   when Android asks.

Your data is stored on the device and survives app restarts.
